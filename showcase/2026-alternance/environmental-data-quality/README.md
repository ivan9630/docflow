# Environmental Data Quality — HOLIS

Projet personnel de qualité de données environnementales : parsing CSV, contrôle des unités, doublons, valeurs anormales, consolidation multi-sites et estimations simplifiées.

Exécuter : `python app.py` ; tester : `python -m unittest discover -s tests -v`.

Les facteurs d'émissions sont **fictifs** : ce n'est pas un bilan carbone ni une ACV homologuée.
