# Industry4 Quality API — WOODOO

Prototype REST Python pour la gestion de défauts industriels fictifs. `GET /api/issues`, `POST /api/issues`, `GET /api/kpis` ; validation d'entrées et tests unitaires. Démarrage : `python app.py` ; tests : `python -m unittest discover -s tests -v`. Démonstrateur backend local, sans interface front-end ni authentification, non destiné à la production.
