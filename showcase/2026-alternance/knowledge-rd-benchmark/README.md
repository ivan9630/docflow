# Knowledge R&D Benchmark — Devoteam

Prototype personnel de recherche documentaire et de mesure de pertinence. Classement lexical d'extraits de connaissances, comparaison des résultats et évaluation `recall@k`.

`python app.py` ; `python -m unittest discover -s tests -v`.

Il ne s'agit pas d'un LLM ni d'un RAG génératif complet : la recherche lexicale constitue une brique de R&D isolée.
