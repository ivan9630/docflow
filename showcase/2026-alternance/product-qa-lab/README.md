# Product QA Lab — LAB EVENT

Projet personnel Python de triage des anomalies et de validation de critères d'acceptation. Modèle de tickets, priorisation, contrôle des user stories et tests unitaires.

Exécuter : `python app.py` puis `python -m unittest discover -s tests -v`.

**Démonstrateur sans client réel.** Le barème de priorité est fictif ; aucune intégration Jira/Playwright n'est revendiquée.
