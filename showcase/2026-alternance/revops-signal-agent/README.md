# RevOps Signal Agent — JobTeaser

Pipeline décisionnel **déterministe** de qualification de comptes B2B : validation, dédoublonnage, scoring ICP, signaux de recrutement / financement fictifs, priorités et actions soumises à revue humaine.

`python app.py`; `python -m unittest discover -s tests -v`.

Pas de LLM, scraping ou CRM connecté, et aucun envoi de message. Données de démonstration.
