# RL Experiment Lab — VO2 Group

Prototype pédagogique Python d'un bandit multi-bras epsilon-greedy, comparaison à une politique aléatoire, reproductibilité par graine et évaluation des récompenses. Aucun LLM n'est entraîné ici.

Exécuter : `python app.py` et `python -m unittest discover -s tests -v`. Données synthétiques.
