# Roadmap SEO / tracking / UX (exemple de tickets)

| Ticket | Priorité | Responsable type | Critère de recette |
|---|---|---|---|
| WEB-01 | P1 | Développeur | Event `cta_click` reçu dans Matomo après consentement, absent avant consentement |
| WEB-02 | P1 | Webmasters | Chaque page stratégique possède un H1 et une méta description unique |
| WEB-03 | P2 | UX | Test A/B du CTA : hypothèse, métrique primaire et période documentées |
| WEB-04 | P2 | Équipe SEO | Audit mensuel des balises title, canonical, sitemap, maillage |
| WEB-05 | P2 | Analytics | Rapport mensuel trafic, rebond, durée, conversions avec définitions partagées |

**Définition de terminé :** validation fonctionnelle, contrôle qualité des balises, documentation et communication aux équipes digitales. Les tests sont des exemples, pas des déploiements réels.
